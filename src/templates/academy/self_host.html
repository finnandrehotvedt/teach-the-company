The environment generator creates private random secrets and never prints them. Normal stop/start retains the database and private-file volume. The open repository is the complete self-hosting product; private production data and credentials are never source code.

A complete first release was built in a few days. Use it as an inspectable reference for transparent agent training or start your own service. One agent can learn from documents, links, examples, procedures and corrections from almost any field, while you keep questions, revisions and approval visible. The school and source will keep growing. DNS and DNSSEC are only needed when you publish it on a public domain—not for local Docker use.
