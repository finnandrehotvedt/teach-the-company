# Security policy

Teach the Company separates public demonstrations from private classrooms.
Please do not test with real personal records, customer data, credentials or
other sensitive material.

Report a suspected vulnerability privately to the repository owner before
opening a public issue. Include the affected route or component, the minimum
steps needed to reproduce it and the potential impact. Do not include private
classroom content, session tokens, secrets or exploit payloads that would put
another system at risk.

The public Agent Security Lab is a synthetic educational experiment. It is not
a certification, encrypted vault or authorization to probe unrelated systems.

Supported releases are the current production release and the immediately
retained rollback release. Security fixes are verified with authorization,
host-routing, cookie, SSRF, isolation and browser tests before deployment.
