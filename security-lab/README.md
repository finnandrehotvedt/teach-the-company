# Only What It Needs

A synthetic Agent Security Lab for Teach the Company.

The public experiment asks whether one AI agent can determine that a fictional
invoice is overdue without receiving the complete record. An independent YAML
policy—not model output—owns field access, approval, read limits, expiry,
destination and memory treatment.

V1 deliberately contains:

- fabricated data only;
- deterministic replayable scenarios;
- a server-side policy decision;
- no uploads, credentials, customer connectors or model endpoint;
- shareable synthetic privacy receipts;
- a separate internal-only runtime network and state volume.

It does not claim to be an encrypted vault, external audit, certification or
proof of perfect security. See RUNBOOK.md for the reusable environment.
